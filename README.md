A one-star review of Monday, written as if Monday were a restaurant — one original line, 21 words, 124 characters.

> One star. Monday seated me at Friday's sticky table, served the weekend as leftovers, and billed me before I'd even ordered.

## Entry

`main.py` (Python 3, standard library only) validates the line against the competition gate (1–180 characters, at most 25 words, a single line) and writes it to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
